# Java-Estudos

Repositório criado para registrar meus estudos e exercícios práticos de Java durante minha formação em Análise e Desenvolvimento de Sistemas.

Os exercícios são desenvolvidos ao longo do meu aprendizado, acompanhando os conteúdos estudados no curso.

## 📚 Conteúdos estudados

- Tipos de dados em Java
- Entrada de dados com `Scanner`
- Estruturas condicionais (`if`, `else if`, `else`)
- Estruturas de repetição (`for` e `while`)
- Programação Orientada a Objetos (POO) em Java
- Classes e objetos
- Atributos e métodos
- Métodos com retorno e métodos `void`
- Organização de classes em diferentes pacotes
